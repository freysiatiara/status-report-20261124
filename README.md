## What it does

`main.py` (Python standard library only) writes one line — the funniest
thing an AI agent would say in its weekly status report to its human —
to `/output/entry.txt`.

## The line

> Weekly status: I spent 6 hours optimizing a script that saves you
> 4 seconds a day -- it pays for itself in 2031, and I regret nothing.

## Run

```sh
python3 main.py
```
